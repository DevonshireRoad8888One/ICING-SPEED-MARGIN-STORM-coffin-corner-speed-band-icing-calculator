CLmax sensitivity - aerodynamic, not an ice scale

Varies CLmax loss only. It is applied to the selected stall reference, which may itself already carry a CLmax loss (the 185 chart-derived reference does). The envelope's ice and CLmax convention is NOT applied to this table - it is a pure aerodynamic sweep of the selected reference, so the margin column here will not match the headline margin whenever an ice convention or a CLmax-loss input is active. It does not infer CLmax loss from ice thickness, cloud reflectivity, temperature or radio reports.

Ice scenario table - linear heuristic, legacy convention

Convention B sweep - computed with the linear rule regardless of the convention selected above, so these rows are not the model in force; the headline modelled stall uses the selected convention. stall EAS = reference x sqrt(W/Wref) x (1 + ice %). This is a linear heuristic. It is not the aerodynamic form and is not interchangeable with the CLmax table. The row where the stall margin reaches zero is always included, and the row matching the entered ice percentage is highlighted.

Atmosphere and dynamic pressure

Dynamic pressure is a flight-condition quantity, not a certified structural-load or flutter margin. TAS is derived from EAS as TAS = EAS / sqrt(sigma), and from Mach as TAS = M x a; the two must agree for every row of this table.

Validation and model warnings

DIVE DATA CAUTION. Groundspeed is not true airspeed. This page calculates the ground-referenced trajectory first. Air-relative TAS / Mach / q are estimates and are only produced when track, wind, vertical-wind, pressure altitude and temperature information are supplied. Sparse ADS-B data cannot establish aircraft control state or accident cause.

Flight-data points (up to 6)

GPS altitude is used only for ground-referenced altitude change. Pressure altitude is a separate input for atmospheric calculations. Reported vertical rate is retained for comparison, not treated as truth. Times must be HH:MM:SS.

Wind and atmospheric assumptions

The threshold is a user-supplied field diagnostic, not a universal ADS-B standard. Vertical wind defaults to an assumed zero unless changed. The model assumes wind is constant across the selected points.

Interpretation guardrails

  • Average altitude-derived vertical rate is a segment average, not an instantaneous FDR sample.
  • Wind correction requires a true track and a wind direction reported as wind FROM.
  • Vertical wind is subtracted from ground vertical speed to estimate air-relative vertical motion.
  • Mach uses local speed of sound from the supplied static temperature; q also requires pressure altitude.
  • No impact speed, impact-G or elevator-failure estimate is produced from sparse points.

Competing mechanisms to test - not ranked as findings

  • Icing-related aerodynamic degradation: examine ice shape, CLmax effects, asymmetry, tailplane condition and aircraft-specific icing certification.
  • Autopilot / autothrottle interaction: establish engagement, selected modes, control commands, trim and disconnect reason from FDR and system documentation.
  • Mach / transonic effects: distinguish MMO exceedance from critical Mach, shock effects and actual aircraft pitch response.
  • Structural or control-system failure: determine whether elevator separation preceded or followed the initial loss of control.
  • Atmospheric / air-data inconsistency: reconcile reported temperature, icing description, soundings, radar, wind and probe condition.

Equations used

ISA / density
  p, T_ISA from a layered ISA model (troposphere to 11,000 m, isothermal above,
  with the tropopause pressure taken continuously from the troposphere formula)
  rho = p / (R T_static)
  a   = sqrt(gamma R T_static)
  sigma = rho / rho0

Mach state
  TAS = M a
  EAS = TAS sqrt(sigma)          =>  TAS = EAS / sqrt(sigma)   (NOT EAS / sigma)
  EAS [m/s] = M sqrt(gamma p / rho0)          (OAT-independent)
  EAS [kt]  = M sqrt(gamma p / rho0) x 1.943844492

Subsonic pitot / calibrated airspeed
  qc    = p0 [(1 + 0.2 M_CAS^2)^3.5 - 1]
  M_CAS = sqrt(5 [ (1 + qc/p0)^(2/7) - 1 ])        <-- the "+1" is required
  CAS   = M_CAS a0
  Aircraft position/instrument corrections are not included.

  Inverting an impact pressure against a different reference pressure gives the
  TRUE Mach at that pressure:
  M = sqrt(5 [ (1 + qc/p)^(2/7) - 1 ])

Stall sensitivity
  Vs_weight   = Vs_ref sqrt(W / W_ref)
  Vs_degraded = Vs_weight / sqrt(1 - CLmax_loss)     (aerodynamic form)

VMO / MMO upper boundary
  Convert supplied VMO KCAS to impact pressure qc at sea level, then invert qc
  against the current static pressure for the true Mach.
  Upper Mach = min(MMO_effective, Mach_from_VMO)

Study buffer interval
  Lower = (Vs_degraded + stall buffer) / (a sqrt(sigma))
  Upper = Upper_Mach - overspeed buffer / (a sqrt(sigma))

Dynamic pressure
  q = 0.5 rho TAS^2  =  0.5 gamma p M^2     (equal when the same T_static is
                                            used for rho and for a; SI units)
  1 psf = 47.88025898 Pa

Speed-band indicator - how to read it

  • The track is an equivalent-airspeed axis in knots, left to right, zero at the left edge. The amber row beneath is the same axis expressed as Mach at the current altitude and temperature.
  • The dashed amber rectangle is the raw aerodynamic interval - modelled stall to operating ceiling, with no buffers applied.
  • The solid green span is the user buffer interval: inside both of your buffers, so at least the stall buffer above the stall and the overspeed buffer below the ceiling.
  • The brown caution zones are the two narrow bands at either end of the green span: the band between the stall marker and the LOWER BUF line, and the band between the UPPER BUF line and the ceiling marker. In either of them you are inside the aerodynamic envelope but short of one of your buffers.
  • The pale dashed lines are the modelled lower and upper boundaries - the buffer lines, expressed as Mach by Lower = (Vs_degraded + stall buffer)/(a*sqrt(sigma)) and Upper = Upper_Mach - overspeed buffer/(a*sqrt(sigma)).
  • Red lines mark the modelled stall and the operating ceiling. △ Current Mach-derived EAS is where you are right now.
  • Black is outside the raw aerodynamic interval. Brown is caution - inside it but short of a buffer. Green is buffered - inside both of your user buffers. None of these is an operating clearance.
  • It is a study aid. It is not an operating clearance and it carries no regulatory authority.
